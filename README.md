# 空气交互舱 · Air Interaction Pod

## 产品化优化版

本版本在原阶段 1~3 功能基础上完成网站化整理：重做首屏信息层级和移动端布局，将调试参数收进“高级校准与识别诊断”，加入本地处理隐私提示、加载状态、绘画撤销、清屏确认与操作反馈。停止或重新开启摄像头时会保留已有笔画；网站仍为纯前端，摄像头帧仅在浏览器内用于手势识别。

### 2026-09-15 性能修复

- 默认从双手识别改为“单手·流畅”，双手分工与双手独立仍可主动开启；
- 画面增强改为暗光时手动开启，避免每帧滤镜和画面复制；
- 摄像头优先请求较低输入分辨率，舞台与作品导出仍保持 640×480；
- 识别耗时较高时骨架自动隔帧绘制，控制层最高约 30fps；
- 状态栏改为 10fps 更新，关闭高级设置时不再后台绘制标定画布；
- 运行期间关闭会触发全页重绘的扫描线、网格混合和背景模糊效果；
- 连续两秒低于 18fps 时给出明确降载建议。

在「手势表情包机」demo 上升级的体感小电脑雏形：**食指是光标、拇食指捏合是点击**，内含两个可切换的小应用。
纯前端、浏览器本地推理、无需后端、**摄像头数据不出本机**。

- 阶段 1：指尖光标（EMA 平滑）+ 捏合点击（双阈值迟滞）
- 阶段 2：空气乐器（Tone.js，14 种音色 × 2 种演奏法 × 3 种音阶的多模态乐器库，含空气鼓组与连续滑音）
- 阶段 3：指尖粒子绘画（发光拖尾、捏合换色、手势清屏/保存、轨迹回放、PNG 导出）

体感小游戏、完整桌面导航属于后续阶段，本期不含。

## 运行方式（不能直接双击 index.html）

摄像头只在 `localhost`/`https` 下可用，`file://` 必然失败（页面会自检并红字提示）。三选一：

1. **双击 `一键启动演示.bat`**（需本机装 Python）。
2. 本文件夹开终端执行 `py -3 -m http.server 8012`，用**系统 Chrome/Edge** 打开 http://localhost:8012。
3. VS Code Live Server 插件右键打开。

点「▶ 开启摄像头」并授权，首次点击同时解锁音频引擎。MediaPipe、Tone.js 走 CDN，**需要联网**（界面样式为纯手写 CSS，无外部 UI 框架）；识别与发声都在本地运行。视觉为全息 HUD 风格（深蓝黑底+青色科技描边+四角括号+等宽数字）。

## 应用切换

舞台顶部两个模式按钮（或快捷键）：

- **🎹 空气乐器（按 1）**：食指上下移动选音高（越靠上越高），捏合发声，右侧面板可换音色/演奏法/音阶。
- **✨ 粒子绘画（按 2）**：手势见下表，右侧面板有 HSL 光谱取色板（点拖任选颜色+饱和度）、8 个快捷霓虹色、**16 种粒子画笔（含 9 种伪 3D 立体笔刷）**（B 键循环）、按钮和笔画统计。
  - 基础 7 种：霓虹光带（默认）、喷雾星尘、双层丝带、泡泡、十字星光、彩虹流（沿路径自动变色）、火星迸溅。
  - 伪 3D 9 种（纯 2D canvas 用非同心径向渐变/明暗双层/偏移高光/相位翻转模拟体积，零新依赖、可回放）：立体光管、3D光球、扭转缎带、立体挤出、金属串珠、凝胶囊体、螺旋光管、棱面晶体、景深浮粒。

### 乐器库（多模态）

**14 种音色（快捷键 3~9、0、-、=、Q W E R，全部 Tone.js 官方合成、无外部采样；点音色名或按 A 试听固定片段做横向对比）**，按合成家族刻意拉开区分度：
- 物理模型：拨弦（Karplus-Strong，原声感最强）；
- FM 击奏（谐波比/调制指数/衰减刻意拉开）：钟琴（非谐比 3.49+高指数+2.4s 长尾混响）、八音盒（高比 5.4+低指数+0.4s 短衰减+机械拨片噪声，干声）、Rhodes电钢（1:1 暖 FM+低调制指数+钢琴式包络+Phaser 轻染）；
- 加法合成：拉杆风琴（三正弦 8/4/12 尺栓+轻颤音，持续音）；
- 减法拟原声：弦乐群（锯齿压 1.1k 低通+5Hz 揉音+合唱）、竹笛吹管（三角波带通+粉色气息噪声层+揉音）、低频贝斯（三角波圆润低八度，干声）、卡林巴琴（三角波软槌+回声）、氛围铺底（0.45s 慢起音 AM 长音）；
- 金属/电子锚点（故意保留的非原声对比）：金属锣钵（MetalSynth）、芯片方波（8-bit）、失真主音（锯齿→Distortion）；
- 空气鼓组（底鼓 MembraneSynth + 军鼓/镲 NoiseSynth，纵向 5 区，强制离散击打）。
- **去同质化设计**：起音噪声层（noiseTick，击弦/气息瞬态）、起音后渐入揉音（Vibrato）、差异化空间（弹拨/贝斯/电钢干声，钟琴/铺底/弦乐进混响）、不同包络时长，避免"全是锯齿波+同一混响"的电子味。

**2 种演奏法（M 切换）**：
- 离散击打（默认）：移动到音高条带，捏合触发一个音，按下瞬间锁位；
- 连续滑音（特雷门式）：捏住持续发声，上下移动平滑换音（吸附到音阶、0.07s 滑音），**捏合程度 r 实时控制音量**（捏越紧越响），松开止音。鼓组自动锁定离散模式。

**3 种音阶（N 切换）**：大调五声（默认，乱弹和谐）、小调五声（布鲁斯感，配贝斯）、自然大调（7 音）。所有音色经共享混响与限幅器输出，切换音色时释放旧合成器节点，不泄漏。

### 粒子绘画手势

| 动作 | 效果 | 兜底方式 |
|---|---|---|
| 只伸食指（其余手指弯曲）移动 | 落笔发光拖尾；手指收回自然抬笔 | — |
| 拇食指捏合一下 | 在 8 个快捷霓虹色间循环换色 | 按钮「换色」/ C 键 / 点快捷色 |
| 在光谱块上点/拖 | 自选任意颜色（横向色相、纵向明暗，饱和度滑条微调） | — |
| 按 B / 点画笔名 | 在 16 种粒子画笔（含 9 种伪 3D）间循环切换 | — |
| 握拳保持 0.6 秒 | 清屏（有进度环，防止误删） | 按钮「清屏」/ X 键 |
| 张开手掌保持 0.5 秒 | 保存 PNG（黑底发光画，自动下载） | 按钮「保存PNG」/ S 键 |

设计原则：切换应用、保存、清屏等低频操作一律有鼠标按钮兜底，手势只承担高频表达，减少手臂疲劳。

## 模块结构（代码内编号对应）

1. `CFG` + 滑块：手感参数集中、实时可调。
2. `loadModel/loadTone`：模型与 Tone.js 双 CDN 回退，模型 GPU→CPU 回退。
3. `Geo`：手指伸直几何判定，`isPointing` 判定“只伸食指”的落笔姿态。
4. `Tracker`：`pickTwo` 双手选择（主手沿用最近邻锁定、副手取另一只并各自最近邻匹配以减少交叉跳变）、手掌尺度归一化、坐标显式镜像一次。主手走完整交互管线。**双手配合模式（H 键或顶部按钮切换）**：①「分工」（默认，`SecondHand` 控制器）副手品红虚环只发离散功能指令——捏一下=乐器换音色/绘画换颜色，握拳保持 0.6s=乐器换音阶/绘画换画笔，带蓄力环与浮字，不碰主手精细操作；②「独立」副手变实环第二光标，乐器双手各走一个独立语音（`ctrl`/`ctrl2`，可同时出双音/和弦，条带副手位置品红高亮）、绘画双手各画一笔（`Paint.slots.main/sec` 独立笔画），任一只手丢失自动收掉它未完成的音/笔。
5. `EMA` / `PinchFSM`：平滑与捏合迟滞状态机（确认帧+最小间隔+一次性边沿）。
6. 共享 `hand`：检测相位只写、渲染相位只读。
7. `setApp`：instrument/paint 应用状态机。
8. `Instrument`：14 音色工厂（buildVoice，含 MetalSynth 与 Distortion/Chorus/Phaser 效果链）、音阶生成、离散击打/连续滑音、捏合力度映射与共享音频总线；`Paint`：持久层发光笔画、16 种确定性粒子画笔（stamp/step 引擎，9 种伪 3D 靠 shadeHsl 明暗/非同心径向渐变/相位偏移高显出体积，按笔画记录画笔类型）、HSL 光谱取色（hslToHex/hexToHsl，自选色优先于快捷色）、清屏、保存、回放；启动时即把舞台画布初始化为 640×480，避免未开摄像头时被默认 300×150 裁切。
9. 主循环 `frame()`：检测相位（仅新视频帧）与渲染相位（每 rAF）解耦；握拳/张掌用“保持计时+进度环”。
10. 覆盖层：乐器条带 / 绘画光标与进度环 / 捏合连线 / 按下涟漪。

| 参数 | 初始值 | 说明 |

## 识别不稳/丢手怎么办（重要）

MediaPipe 不是按肤色分割的模型，"手和背景同色"本质是**轮廓对比度不足**。按以下顺序排查，调试窗口会实时显示置信度、手掌占比、丢帧率并给出提示：

1. **补光**：让手部光照均匀，避免逆光、暗光（暗光下摄像头噪点多，最容易丢）；
2. **整只手入镜并留边距**：手掌占画面过大（&gt;85%）或贴边都会丢，手离摄像头 40~70cm；
3. **拉开对比**：手和衣袖/背景颜色、明暗尽量不同；
4. **画面增强开关**：默认关闭，只有暗光时才建议开启；它需要逐帧复制并处理画面，会增加性能负担；
5. **单手/双手**：默认“单手·流畅”（numHands=1），用于优先保证常见电脑的跟手性。顶部可切换“双手·分工/双手·独立”（H 键循环）：分工=主手操作、副手（品红虚环，标「2」）隔空切功能；独立=双手各自弹奏/作画（双音、双笔）。双手识别计算量更高，若掉帧明显应切回单手流畅模式；
6. 仍不稳可把"手掌检测/跟踪置信度"调到 0.3~0.4 后点重建（越容易找到手，但误检也略增）。
摄像头请求已指定理想 30fps；若 readout 里 detect 长期低于 20fps，优先换浏览器/关后台占用或换更亮环境。

## 人工验收清单（自动化无法调用摄像头，需本机逐项确认）

**阶段 1 · 光标与捏合**
- [ ] 手往右光标往右；食指到四角，光标也能到覆盖层四角；
- [ ] 手静止时平滑坐标波动 ≤ 2~3px；慢画圆圆滑、快横扫不明显滞后；
- [ ] 张开乱挥不增加“按下”；r 停在两阈值之间状态不跳；按下/松开严格成对。

**阶段 2 · 空气乐器（含乐器库）**
- [ ] 离散模式：不捏不响、一捏一声、无连发爆音，高亮条带与音高一致；
- [ ] 14 种音色逐个切换都能正常发声、无叠加残留；重点听相邻音色区分度（钟琴 vs 八音盒、弦乐 vs 竹笛、电钢 vs 风琴）；用「试听片段」按钮/A 键横向对比；鼓组 5 区分别是开镲/闭镲/军鼓/通鼓/底鼓；
- [ ] 连续滑音：捏住持续发声、上下移动平滑换音、捏紧变响松开止音，手丢失时声音自动停；
- [ ] 3 种音阶切换后条带数量/标签随之变化，鼓组时音阶选择器隐藏；
- [ ] 音频显示“已就绪”，控制台无 suspended 警告；检测 ≥25fps，延迟主观 <100ms。

**阶段 3 · 粒子绘画**
- [ ] 只伸食指才出笔画，五指张开/握拳移动时不留痕（抬笔正确）；
- [ ] 捏合只换色、不在画上点出杂点；换色后新笔画是新颜色；
- [ ] 握拳不到 0.6 秒松开不会清屏，保持到进度环走满才清，且只清一次；
- [ ] 张掌保持能下载一张 640×480 黑底 PNG，画面与舞台一致；
- [ ] 轨迹回放顺序与手绘一致，笔画之间没有多余连线；
- [ ] 切回乐器再切回绘画，已有画面不丢失（切应用不清屏，只有清屏手势/按钮清）。
